# Premium Learning信息

探索您的订阅优势、续订选项和学习利用率报表。 选择下面的链接页面名称以了解详情。

* [订阅权益和续订](/help/main-guide/premium-learning-subscription/subscription-benefits-and-renewal.md)：了解订阅中包含什么以及如何保持对学习内容的访问权限。
* [利用率报告概述](/help/main-guide/premium-learning-subscription/utilization-reports/utilization-report-overview.md)：了解利用率报告涵盖哪些数据、谁可以请求这些数据，以及包含哪些历史数据。
* [了解您的摘要表](/help/main-guide/premium-learning-subscription/utilization-reports/utilization-report-summary-sheet.md)：了解关键指标、注册趋势、完成情况、出席情况和认证。
* [了解注册详细信息表](/help/main-guide/premium-learning-subscription/utilization-reports/utilization-report-enrollment-details-sheet.md)：查看学习者注册数据、课程进度、重要日期和出席详细信息。

# 订阅权益和续订

探索Premium Learning订阅和Premium Learning +私人培训订阅中包括的优势，从按需教育到实践学习和专家支持。 了解贵组织如何续订您的订阅以保持对学习内容的访问不中断。

## Premium Learning订阅中包含哪些好处？

**Premium Learning订阅提供以下访问权限：**

- 可在企业范围内使用Adobe的顶级学习平台
- 无限制地访问按需培训视频
- 访问学习环境以进行动手练习和实验
- 按角色和行业划分的个性化同类群组学习历程
- 参加所有虚拟公共思想领导力会议（创新研讨会）
- 获得后同类群组1:1专家指导以获取故障排除和特定环境问题
- 免费使用Adobe认证凭证（见下文说明）

**Premium Learning +私人培训订阅提供以下访问权限：**

- 可在企业范围内使用Adobe的顶级学习平台
- 无限制地访问按需培训视频
- 访问学习环境以进行动手练习和实验
- 按角色和行业划分的个性化同类群组学习历程
- 参加所有虚拟公共思想领导力会议（创新研讨会）
- 获得后同类群组1:1专家指导以获取故障排除和特定环境问题
- 免费使用Adobe认证凭证（见下文说明）
- 访问私人和个人化培训
- 访问打开的沙盒以在防失败环境中进行练习

>[!NOTE]
>
> 免费认证优惠券不适用于所有Access或按需学习订阅用户（以前称为Adobe数字学习服务）。

## 我的学习订阅访问权限即将结束。 如何保持对学习内容的访问权限？

要继续无中断访问您的学习订阅和内容，请让贵组织联系Adobe客户经理。 他们可以引导您了解可用的续订选项。

# 了解您的注册详细信息表

## “注册详细信息”表显示什么？

**注册详细信息**&#x200B;工作表提供了摘要工作表后面的详细数据。 其中包括学习者信息、课程详情、进度、出席情况、完成状态以及关键注册和上课日期。

阅读学习利用率报告的“注册详细信息”选项卡的快速参考。 此工作表是摘要工作表之后的数据 — 每个学习者注册一行。

- **学习者/电子邮件** — 注册对象。
- **形式** — 培训格式：独立ILT（实时讲师课程）、同类群组（多会话计划）或自学/按需。
- **格式** — 如何传送，如虚拟教室或自学。
- **产品** — 课程涵盖哪些Adobe产品。 课程可列出多个。
- **课程/培训** — 特定课程标题。
- **实例/会话** — 学习者注册的特定类运行/会话（或无计划会话的自学内容的“默认实例”）。
- **状态** — 学习者在该课程中的位置：已完成、正在进行或未开始。
- **进度** — 小数完成进度（1 = 100%完成，0 =未启动，值介于两者之间，表示部分）。
- **逗留时间（分钟）** — 学习者已登录课程的分钟数。
- **注册日期** — 学习者注册的时间。
- **已开始** — 学习者何时开始课程（如果未开始，则为空）。
- **截止日期** — 目标完成日期（如果已设置）。
- **已完成** — 学习者完成的日期/时间（如果学习者已完成）。
- **过期** — 标记截止日期是否已过期且未完成。
- **类交付状态** — 类本身是否已运行：“已交付”、“已计划”或“进行中”。 仅适用于ILT/同类群组；对于自定节奏，留空。
- **ILT/同类群组出席情况** — 学习者是否出席实时会话：已参加、部分参加、无显示、已计划或进行中。 仅适用于ILT/同类群组。
- **课程开始/课程结束** — 实时会话的计划日期。
- **Month-Year** — 类/会话所在的月份。 这是“摘要”工作表上“按月注册趋势”表的源。
- **时区** — 类运行所在的时区。

## 需要注意的一些事项

- 每一行=一个课程注册，而不是一个学习者。 具有3个课程的学习者会出现3次。
- 自定进度的行将始终显示班级交付状态、出席情况、班级开始/结束以及时区的空白 — 这些列仅适用于实时会话。

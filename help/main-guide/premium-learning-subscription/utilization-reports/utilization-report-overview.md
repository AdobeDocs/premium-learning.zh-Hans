# 利用率报表概述

了解Premium Learning订阅的利用率报表，包括这些报表涵盖的学习活动、谁可以请求这些报表、它们包含多少历史数据，以及当前报表与以前报表不同的原因。


## 什么是利用率报告？

利用率报告提供了整个组织范围内的学习活动视图，包括注册、课程完成、出勤情况、认证和总体培训使用情况。

## 谁会收到利用率报告？

利用率报告可应请求提供给贵组织的企业联系人(POC)，POC负责管理或监督您的Premium Learning订阅。 个别学习者不会收到此报表。

## 每个月报告中包含多少历史数据？

每份月度报告都是累积性的，并且从2026年6月开始包含所有可用数据。 以后的每个报告都将以上一个报告为基础，以便您可以在单个报告中查看历史和当前学习活动。 2026年6月标志着向当前学习平台的过渡，因此这些报告中不包含来自早期平台的数据。

## 为何报告不包含2026年6月之前的数据？

每月利用率报告包括从2026年6月开始当前学习平台的数据。 旧版平台的历史数据可在单独的报表中获取。 企业联系人可以通过[联系我们](https://adobe.service-now.com/adls?category=10)来请求副本。

## 为什么新的利用率报告与以前的报告有所不同？

新的利用率报告是从我们当前的学习平台生成的，该平台使用与旧版平台不同的数据模型。 因此，某些字段和数据点已发生更改。

更新的报表还包含以前不可用的其他见解，例如更详细的完成信息和学习者不秀的可见性，让您更全面地了解组织的学习活动。

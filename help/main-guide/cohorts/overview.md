# 同类群组 — 概述

获得在Adobe Premium Learning同类群组中取得成功所需的一切。 选择链接的主题名称（每个项目的第一个字）以跳转到该部分。

* [同类群组结构](/help/main-guide/cohorts/cohort-structure.md)：了解同类群组的工作方式，包括每周一次的现场讲座、自定进度的模块和测验、Capstone挑战以及规划时间。
* [参与率期望](/help/main-guide/cohorts/participation-expectations.md)：了解完成同类群组所需的条件，包括每周两次的现场会话出席情况、自定进度的模块和测验以及Capstone挑战。
* [注册和设置](/help/main-guide/cohorts/enrollment-and-setup.md)：了解注册后的预期情况，包括确认电子邮件、实时会话邀请、准备工作、沙盒访问和讨论区设置。
* [您的学习历程](/help/main-guide/cohorts/learning-journey.md)：了解如何跟踪出席情况、如何通过测验和Capstone挑战保持进展以及您同类群组结束时会发生什么。
* [同类群组实时会话的系统要求](/help/main-guide/cohorts/cohort-live-session-system-requirements.md)：查看实时会话的Adobe Connect、硬件和软件要求。
* [社区](/help/main-guide/cohorts/community.md)：通过&#x200B;**[!UICONTROL 我的中心]**&#x200B;中的讨论区，与您的同类群组、讲师和主持人联系。
* [同类群组支持](/help/main-guide/cohorts/support.md)：查找缺少的日历邀请，从&#x200B;**[!UICONTROL 我的学习]**&#x200B;启动实时会话，并获取有关沙盒环境和Adobe Connect的帮助。

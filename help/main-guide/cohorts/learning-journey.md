# 您的学习历程

## 如何跟踪同类群组的出席情况？

仅根据实时会话的参与情况跟踪出席情况。 如果您无法实时参加会议，则以后观看录制将不会计入出席记录。

## 为何需要现场出席？

实时会话提供了录制无法完全复制的机会。 通过参加直播，您将能够在交互式环境中与同行一起提问、参与讨论并练习。 我们鼓励每个人尽可能优先参加每个会议。

## 如何在同类群组中保持按部就班状态？

小测验是每周自学课程的一部分。 这些内容可帮助您检查您对所涵盖的主题和概念的理解。

同类群组结束后，您将完成约40个问题的最终评估测验，以总结您的学习。

您还可以通过完成Capstone Challenge项目来跟踪进度。 此分组活动可让您有机会将所学知识应用于现实场景。

## 同类群组结束时会发生什么？

最后几周包括一个应用您的学习的Capstone挑战和一些认证准备时间，让您为Adobe认证考试做好准备。

同类群组完成徽章将在[我的成就](https://experienceleague.adobe.com/zh-hans/premium/my-achievements)中提供。

# 参与率预期

**实时会话是同类群组的一个核心组成部分，预计每周出席两次。 仅根据实时参与率跟踪出席情况。** 这些实时交互式会议让您有机会与Adobe专家交流、提问、参与讨论并与同行一起实践。 虽然会话录制可供审阅，但观看录制内容并不计入您的出席情况。

**完成点数需要Capstone项目和配对审核。** 通过引导式顶石项目演示精通。 将您的学习应用到实际挑战中，然后在结构化的审核会话中与同行交流反馈。 学习者必须完成capstone项目才能获得同类群组完成信用。

**自学课程和测验对于准备实时会话和成功完成项目至关重要。** 在直播之间根据自己的进度灵活学习。 访问异步模块、实践实验室和讨论活动，以加深您的理解并在现实情景中应用关键概念。

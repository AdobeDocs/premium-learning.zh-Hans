# 同类群组结构

## 同类群组结构如何？

**实时会话**

您每周都将参加由Adobe专家主持的两场时长90分钟的现场会议，在那里您将深入探索Adobe解决方案。 这些会议还让您有机会通过小组讨论和互动活动与同类群组中的其他人进行交流。 几周后，一位嘉宾演讲者将分享最佳实践或真实使用案例。

**自学活动**

在两次直播课程之间，您将完成包括阅读、视频和动手练习在内的自助在线模块，以帮助您应用所学内容。 每个模块结束后，参加一个简短的测验可帮助您检查自己的理解。 我们建议每周预留2 - 4小时以完成在线学习和测验。

**Capstone挑战**

作为同类群组的一部分，您还将与一组同行协作开展凯普斯通挑战项目。 这是一个把所学的一切付诸现实的机会。 您的小组会提供简短的演示，以分享您的工作并从Adobe讲师和学习者那里获得反馈。

# 我有Premium Learning订阅。 我可以访问哪些学习选项？

## 基于同类群组的学习

同类群组学习融合了专家指导的指导、讨论和实际应用，同时在2-8周内促进共享进展、社区和协作。 与Adobe专家和您的同行一起参与实时学习。 在现场讲座之间学习自控进度的活动和测验。 通过引导式顶石项目演示精通。 成功完成同类群组后，学习者将获得完成徽章，并更接近认证就绪状态。

参与同类群组：[开始前须知](/help/main-guide/cohorts/overview.md)

## 现场讲师课程

我们的实时课程由专家讲师指导，与Adobe Experience Cloud产品团队合作开发。 借助Premium Learning，我们的讲师将指导您通过产品沙箱中的实践练习来进行交互式会话。 您将获得每门课程的幻灯片、活动指南和完成徽章。

参加实时讲师课程：[开始前须知](live-instructor-course-readiness/overview.md)

## 按需课程

按照您自己的进度表学习根据实时讲座设计的课程。 在我们要求的学习沙箱中通过实践产品练习深入研究，并通过引导式活动、课程材料和完成徽章强化您的技能。

此处未列出问题？ [联系我们](https://adobe.service-now.com/adls?category=8)。
